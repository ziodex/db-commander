# Db Commander

An open-source desktop SQL workbench for Windows, macOS and Linux.

Active source code and documentation are maintained on the [development branch](https://github.com/ziodex/db-commander/tree/development). See the [developer README](https://github.com/ziodex/db-commander/blob/development/README.md) for setup and build instructions, and the [user guide](https://github.com/ziodex/db-commander/blob/development/docs/USER_GUIDE.md) for application workflows.
